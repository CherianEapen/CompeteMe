  > What Is Windows Local Account Management?
  > Windows local account management is the process of creating, configuring, securing, and removing user accounts stored directly on individual Windows devices.
  > On shared workstations and kiosk-style devices, manual account administration can create inconsistent privileges and leave orphaned accounts after employee offboarding. With Windows unified endpoint management (UEM), IT admins can manage local accounts remotely across multiple devices instead of configuring each device individually.
  > A local account is defined on an individual Windows device, which acts as its security authority. A domain account normally authenticates against an organizational directory service and may have permissions to access local and domain resources.
  > Windows can allow offline sign-in when a domain controller is unavailable. This requires valid cached domain credentials and enabled credential caching. However, users cannot access network resources that require domain validation until the domain controller becomes available.
